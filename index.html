Scanning guide

  1. Use a flat, well-lit surface with a contrasting background. Avoid glare.
  2. Start the camera and fit all four edges inside the preview, or import an image.
  3. Capture, adjust the four corners, rotate if needed, and add the page. Edge detection checks light and dark regions and page boundaries; inspect the corners, especially on busy backgrounds.
  4. Choose an enhancement before adding a page. OCR works best with clear, upright text.
  5. Use each page's Text / identify button, review the result, then download a PDF or text file.

PDFs preserve image proportions and carry Unicode search text, including your corrections. Corrected text uses approximate line positions; it does not change the visible page image. Search and selection support varies by PDF reader. UTF-8 text export is also available. Page images and reviewed text are saved locally for recovery; clearing browser data removes them. Export before clearing a draft. Offline scanning and barcode recognition work after the app is cached. Download the selected OCR language first and check its readiness before going offline.
